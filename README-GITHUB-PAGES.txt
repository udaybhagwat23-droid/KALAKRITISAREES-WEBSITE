KALAKRITI SAREES — UPDATED PORTFOLIO WEBSITE

This package contains the static KALAKRITI portfolio website and its local product catalogue.

UPDATES IN THIS VERSION
- Homepage hero uses the newly supplied KALAKRITI palace-and-mannequin banner.
- Product cards show the open-saree photograph first.
- On mouse hover (or keyboard focus), the product card swaps to the paired mannequin photograph.
- The six saree collection cards use mannequin photographs.
- Budget/price cards retain product photography.
- Existing collection navigation, product detail pages and demo cart are retained.

IMPORTANT
- The cart is a front-end demonstration stored in the visitor's browser. It does not submit Shopify orders or accept payments.
- This is a static website; Shopify Liquid and Shopify's live inventory/checkout are not running here.
- Keep index.html, products.js, products.json and the assets folder together.

GITHUB PAGES
1. Create a public GitHub repository.
2. Extract this ZIP and upload all files and folders from inside it to the repository root.
3. Confirm index.html is in the repository root.
4. In GitHub, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish and use the URL it displays.

To update later, edit the files in the repository and commit the changes. GitHub Pages will redeploy.
