KALAKRITI — NETLIFY FRONTEND PREVIEW

DEPLOY
1. Extract this ZIP.
2. In Netlify choose Add new site > Deploy manually.
3. Upload the extracted folder (the folder containing index.html, products.js and assets/).
4. Netlify publishes the static frontend.

WHAT IS INCLUDED
- KALAKRITI home page based on the supplied Updated Horizon homepage configuration and visual reference.
- Four budget cards and six named saree collection cards.
- Product listings and product detail views using the supplied catalogue and product photographs.
- Functional Add to Cart and cart quantity/removal controls using browser localStorage.
- Responsive desktop/mobile layout.
- Original Shopify theme source archive in source/shopify-theme-source.zip for reference.

IMPORTANT LIMITATION
This is a standalone frontend portfolio preview. Shopify Liquid cannot be executed by Netlify's static hosting. The supplied Shopify source archive is preserved separately and is not the runtime for this static site. The cart is a local demo cart; it does not sync with Shopify inventory, create Shopify orders, or provide checkout/payment. The page uses the provided source settings, catalogue, photos and reference design, but a static conversion cannot guarantee pixel-for-pixel rendering parity with Shopify's hosted Horizon runtime.
