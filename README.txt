KALAKRITI WEBSITE PACKAGE

Open index.html in a modern browser to preview the responsive storefront.
Included: 55 product records from KALAKRITI-all-products.csv, available product photos from the supplied ZIP archives, prices, descriptions and SEO metadata in products.json, and the visual reference banner crop from the supplied store screenshot PDF.

This is a standalone front-end preview. Product enquiries are demo links; live Shopify checkout, inventory sync, customer accounts, shipping and payment processing are not connected. To publish it as a live Shopify theme, the theme needs to be installed in Shopify and connected to live collection/product resources.

Also included: shopify-theme-source.zip, the supplied theme source archive, for Shopify theme upload/review. The standalone preview and the Shopify theme source are separate deliverables.
